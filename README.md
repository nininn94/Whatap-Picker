## 해결하려는 문제

기존 오프라인 부스에서는 실물 뽑기판을 활용한 경품 이벤트를 운영해왔습니다.  
참여율은 높지만 설문 작성 → 인적사항 확인 → 뽑기 → 경품 지급이 순차적으로 진행되어 한 명당 처리 시간이 길어지는 구조적 문제가 있었습니다.

- 설문 작성과 현장 확인이 같은 지점에서 이루어져 대기 시간이 증가합니다.
- 전화번호, 회사명, 이메일 등 리드 정보의 정확도를 현장에서 수동으로 확인해야 합니다.
- 등수별 경품 수량과 일자별 잔여 수량을 운영자가 직접 관리해야 합니다.
- 이벤트 결과와 설문 데이터가 분리되면 사후 분석과 영업 후속 조치가 늦어집니다.
- 매 행사마다 뽑기판·칠판·거치대를 제작하고 이동하는 데 추가 비용과 인력이 소모됩니다.

## 결과물 소개

**WhaTap Picker**는 오프라인 부스 이벤트 전 과정을 디지털화한 웹 기반 솔루션입니다.

### 참여자 흐름

1. 운영자가 관리 페이지에서 설문 질문을 구성하고 QR코드를 발급합니다.
2. 참석자는 QR코드를 스캔해 모바일로 설문에 참여합니다.
3. 설문 완료 후 부스 노트북에서 이름과 전화번호 뒷자리를 입력해 본인을 확인합니다.
   - 동명이인이 있을 경우 회사명을 함께 표시해 구분합니다.
   - 일 1회 참여 제한이 적용되며, 중복 시 안내 메시지가 표시됩니다.
4. 디지털 뽑기를 진행하고 등수를 확인합니다.
5. 스태프가 해당 등수의 경품을 증정합니다.

### 운영자 관리 기능

- 설문 질문 구성 및 QR코드 발급 (PNG)
- 경품 등수별 재고 현황 입력 및 자동 차감
- AI 기반 Lifecycle Stage (MQL / Known Lead) 자동 분류
- 수집된 리드 필터링·키워드 검색·CSV 내보내기 (Export)
- 행사별 통계 대시보드 + LLM 마케팅 인사이트
- Google Sheets 행사별 자동 연동 (제출 시 append)

## 기대 효과

- **비용 절감**: 뽑기판·칠판·거치대 제작 및 이동에 소요되던 비용이 없어집니다.
- **처리 시간 단축 및 리드 수집 증가**: 수작업 확인 과정이 자동화되어 더 많은 참석자를 빠르게 처리할 수 있습니다.
- **이벤트 횟수 증가**: 기존 일 2회에서 3회 이상 운영이 가능해져 리드 수집 기회가 늘어납니다.
- **자동 리드 분류 및 통계 리포트**: AI가 설문 답변을 분석해 리드 품질을 자동으로 분류하고 리포트로 출력합니다.
- **중복 참여 방지 및 재고 자동 관리**: 동일인의 재참여를 차단하고, 경품 재고를 뽑기 결과에 따라 자동으로 차감합니다.
- **자체 플랫폼 통합 관리**: 설문·QR코드를 별도 외부 플랫폼 없이 한 곳에서 관리할 수 있습니다.
- **소규모 부스 확장성**: 비용 부담 없이 규모와 무관하게 어떤 부스에서도 이벤트를 진행할 수 있습니다.
- **현장 스태프 최소화**: 경품 지급·리드 확인 업무가 자동화되어 운영 인력을 줄일 수 있습니다.
- **브랜드 커스터마이징**: 행사마다 설문 구성과 화면을 브랜드에 맞게 빠르게 수정할 수 있습니다.
- **데이터 실시간 모니터링**: 이벤트 진행 중에도 참여 현황을 실시간으로 확인해 즉각적인 운영 판단이 가능합니다.
